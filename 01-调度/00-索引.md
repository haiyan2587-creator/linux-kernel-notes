# 调度子系统 · 阅读索引

本目录记录 Linux 进程调度子系统的阅读过程。这是索引页，随笔记增加更新。

## 源码地图

| 文件 | 职责 |
| --- | --- |
| `kernel/sched/core.c` | 调度器主干：`schedule()`、`__schedule()`、`context_switch()` |
| `kernel/sched/fair.c` | CFS 完全公平调度器 |
| `kernel/sched/rt.c` | 实时调度（SCHED_FIFO / SCHED_RR） |
| `kernel/sched/deadline.c` | Deadline 调度 |
| `kernel/sched/idle.c` | idle 调度类 |
| `kernel/sched/sched.h` | `struct rq`、`struct sched_class` 等核心定义 |

## 核心数据结构

- `struct task_struct` —— 进程/线程描述符，与调度相关的字段：`state`、`prio`、`policy`、`se`
- `struct rq` —— 每个 CPU 一个运行队列，调度决策的基本单位
- `struct sched_class` —— 调度类的函数表，各调度类按优先级串成链表
- `struct sched_entity` —— CFS 的调度实体，携带 `vruntime`

## 主调用链

```
schedule()
  └─ __schedule()
       ├─ pick_next_task()      // 按 sched_class 优先级依次询问
       ├─ context_switch()      // 切换地址空间与寄存器
       └─ finish_task_switch()
```
