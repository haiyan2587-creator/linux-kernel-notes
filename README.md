# Linux 内核学习笔记

> 读源码，不背 API。

记录系统阅读 Linux 内核源码（v7.4 开发线）的过程。目标是理解子系统之间怎么协作，而不是记住函数名。

## 仓库定位

- **写给未来的自己**：半年后回看，能重新捡起这条思路，而不用从零开始
- **接受纠正**：公开的意义在于有人能指出我读错的地方

## 阅读路线

- [ ] 启动流程：bootloader → `start_kernel`
- [ ] 进程与线程：`task_struct`、内核栈
- [ ] 调度核心：`sched_class`、`__schedule`、`context_switch`
- [ ] CFS：调度实体、红黑树、`vruntime`
- [ ] 负载均衡：调度域、`load_balance`
- [ ] 内存：伙伴系统、per-CPU 页缓存
- [ ] slab / slub：对象缓存
- [ ] 虚拟内存：页表、缺页异常、`mmap`
- [ ] VFS：路径查找、inode 缓存、dentry 缓存
- [ ] 并发：spinlock、RCU、per-CPU 变量
- [ ] 中断：上半部与下半部

## 笔记约定

每篇笔记必须回答四个问题。答不上来，说明还没读懂：

1. **它解决什么问题** —— 没有这段代码会怎样
2. **入口在哪** —— 谁调用它，调用链怎么走
3. **核心数据结构** —— 哪些字段是关键，为什么这么设计
4. **我还卡在哪** —— 未验证的猜测、没看懂的边界条件

第 4 条是最有价值的。承认不懂的地方，比抄一遍注释有用。
